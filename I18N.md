# Sistema de Internacionalização (i18n)

## Como Funciona

O site detecta automaticamente o idioma do visitante:
- **Português (PT)**: navegador configurado em português
- **Inglês (EN)**: demais idiomas

A escolha manual é salva no `localStorage` e mantida nas próximas visitas.

## Onde ficam os textos

Tudo em [data.js](data.js), na seção `i18n`:

```javascript
i18n: {
    pt: {
        'nav.about': 'Sobre',
        'hero.title': 'Software QA Engineer',
        ...
    },
    en: {
        'nav.about': 'About',
        'hero.title': 'Software QA Engineer',
        ...
    }
}
```

As chaves usam ponto (`.`) para organizar por seção: `nav.*`, `hero.*`, `experience.*`, `skills.*`, `domain.*`, `certifications.*`, `projects.*`, `beyond.*`, `contact.*`, `footer.*`.

## Como os textos são aplicados

### 1. Textos estáticos (HTML)

Elementos com o atributo `data-i18n` recebem a tradução automaticamente:

```html
<h2 data-i18n="skills.title">Habilidades</h2>
```

Para traduzir um atributo (como `placeholder`), use `data-i18n-attr`:

```html
<input data-i18n="contact.form.name" data-i18n-attr="placeholder" placeholder="Seu nome">
```

### 2. Conteúdo dinâmico (data.js)

Seções dinâmicas (habilidades, experiência, etc.) usam campos bilíngues:

```javascript
{
    title: { pt: 'Português', en: 'English' },
    description: { pt: '...', en: '...' }
}
```

O site renderiza automaticamente no idioma atual usando a chave correta.

## Adicionar Novas Traduções

1. Adicione a chave em `i18n.pt` E `i18n.en` no `data.js`
2. Se for texto estático, use `data-i18n` no HTML

## API JavaScript

```javascript
window.i18n.translate('en');                    // Muda para inglês
window.i18n.translate('pt');                    // Muda para português
window.i18n.getCurrentLanguage();               // 'pt' ou 'en'
window.i18n.getTranslation('hero.title');       // Tradução da chave
window.i18n.t({ pt: 'Olá', en: 'Hello' });      // Helper para campos bilíngues
```

## Testando Idiomas

```javascript
// Console do navegador (F12)
window.i18n.translate('en');
window.i18n.translate('pt');
localStorage.removeItem('preferredLanguage'); location.reload();
```

## Suporte a Novos Idiomas

1. Adicione o bloco completo no `i18n` do `data.js` (ex: `es: { ... }`)
2. Adicione o idioma em `SUPPORTED_LANGS` no [i18n.js](i18n.js)
3. Adicione o botão no HTML:

```html
<button class="lang-btn" data-lang="es" title="Español">🇪🇸 ES</button>
```

4. Atualize a função `detectLanguage()` em `i18n.js` se necessário
